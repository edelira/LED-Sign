# LED-Sign

A 128×32 RGB LED sign (two P5 64×32 HUB75 panels, ESP32 running ESPHome, with
Home Assistant as the brain). It shows Metra BNSF, Amtrak and freight trains as they
pass the house, planes overhead, kitchen timers, and calendar "leave by" alerts.

- `enclosure/`: 3D-printed frame (OpenSCAD and STL files)
